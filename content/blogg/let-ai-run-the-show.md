YPN inviterte alle mellom 25–40 år til en eksklusiv fagsamling hos Microsoft onsdag 20. november kl. 12–16. Gratis, inspirerende — og med toppledere fra Microsoft Norge på scenen.

## Møt toppledere, se beste praksis og test ut sammen med andre

Bli med på Let AI Run the Show og lær hvordan AI kan løfte din karriere, forsterke ditt nettverk og øke mulighetene for å skape gode resultater.

Hilsen Microsoft Young Professionals og nettverket Young Professionals Norway

## Program

### Sesjon 1: Beste praksis

Hvordan bruke AI-verktøy for å lykkes i jobben og øke karrieremulighetene? Hva mener topplederne i Microsoft er oppskriften på personlig utvikling?

### Pauser

Det ble flere pauser og tid til å bli kjent med de andre som deltok denne dagen. Deltakerne fikk også muligheten til å være med på inspirerende aktiviteter i små grupper.

### Sesjon 2: Test ut

Test ut AI for å bygge karriere, forsterke nettverket og skape resultater. Del erfaringer, hør om kreative løsninger og få større innsikt. La AI ta styringen :)
